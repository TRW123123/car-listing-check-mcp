We process vehicle listing titles, descriptions, optional vehicle specifications, broad location, photo URL strings or counts, shot labels, video URL strings, market and language preferences solely to return listing checks and checklists. Inputs might contain personal information if a user includes it. Do not supply credentials, actual VINs, identification documents, private correspondence or unnecessary personal details. Images and linked websites are never downloaded. We do not generate media, verify vehicle facts or provide legal advice.

Application inputs and results are processed in memory for the request only and are not stored. The application logs anonymous tool name, success/failure and elapsed milliseconds. It does not log text, URLs, IPs, personal details or generated request/trace IDs. Unknown tool names are reduced to “unknown”. An optional analytics dataset, disabled by default, receives only the same anonymous measures.
